The shared backend is maintained separately in [Backend](https://github.com/CONSTR-APLICACIONES-MOVILES/Backend). Organization analytics live in its dashboard, not the regular user's mobile profile.

Private defense notes, credentials and generated build evidence are excluded. Passing tests does not certify physical-device testing, distribution, submission or video delivery.
